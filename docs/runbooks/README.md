# Runbooks

Short, specific, and written for whoever is on call at 3am — not for whoever wrote the system.

| Runbook | When |
|---|---|
| [incident.md](incident.md) | Something is broken and someone has to decide what to do first |
| [restore.md](restore.md) | Data loss, or the quarterly restore drill |
| [payments.md](payments.md) | A gateway is down, or money and the ledger disagree |
| [courier.md](courier.md) | A courier's API or webhooks stop |
| [payouts.md](payouts.md) | A payout batch failed, paid twice, or is stuck |
| [tenant-lifecycle.md](tenant-lifecycle.md) | Suspending, restoring, exporting or purging a tenant |
| [launch.md](launch.md) | Taking a new tenant live, and the go/no-go |
