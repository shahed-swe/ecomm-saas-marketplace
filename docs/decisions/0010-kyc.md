# ADR 0010 — Vendor KYC (Bangladesh)
Status: Accepted · 2026-09-16

- Documents: trade licence, NID (owner), TIN, bank proof (statement or cheque leaf); BIN optional (required if vendor issues VAT invoices). Tenant may mark each required/optional.
- Stored only in `private-kyc` bucket under `t/{tid}/v/{vid}/`; uploads via presigned PUT; admin views via 5-min presigned GET; never CDN; never in public tables.
- Vendor states: `registered → documents_submitted → under_review → changes_requested → approved | rejected`; later `suspended`, `closed`. Transitions recorded in `vendor_events`.
- Duplicate detection signals: same NID hash, TIN, phone, bank account hash within tenant.
- NID and account numbers stored as keyed hash for matching + encrypted value for display to authorised staff.
